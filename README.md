# Amazon Sales Analysis using Power BI

## Project Overview
The Amazon Sales Analysis project is a data analytics project built using Microsoft Power BI to analyze sales performance and gain meaningful business insights from sales data.

## Objectives
- Analyze overall sales performance and revenue.
- Identify top-performing products and categories.
- Track sales trends and patterns.
- Understand customer purchasing behavior.
- Create interactive dashboards for data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and calculations
- Data Visualization
- Data Analysis

## Key Features
- Interactive sales dashboard
- Sales and revenue analysis
- Product and category performance analysis
- KPI cards and charts
- Dynamic filters and slicers
- Business insights through visualizations

## Project Files
- Power BI dashboard file (`.pbix`)
- Dataset used for analysis
- Dashboard screenshots

## Learning Outcomes
This project helped me practice data cleaning, data modeling, DAX calculations, and interactive dashboard development using Power BI.
